# OrgMind Agent

本地部署的公司信息问答 Agent:既能回答文档知识问题("报销流程是什么?"),也能回答组织数据问题("技术部有多少人?""张三的上级是谁?")。所有答案都有来源、可追溯,不瞎编。

## 技术栈

- 后端:Python + FastAPI + LangChain + ChromaDB,大模型 DeepSeek
- 向量化:本地 BAAI/bge-small-zh-v1.5
- 前端:Vue 3 + Vite
